
# 🚀 FlaskUserApp  

A simple yet powerful **Flask-based User Management Application** that demonstrates how to build and manage RESTful APIs using **Python + Flask**.  
This project is beginner-friendly and helps you understand the basics of authentication, routing, and database operations.  

## ✨ Features  
- 🔑 **User Authentication** (Sign Up & Login)  
- 📜 **User CRUD Operations** (Create, Read, Update, Delete)  
- 🗂 **REST API Endpoints** with JSON responses  
- ⚡ Lightweight and easy to set up  
- 🐍 Powered by **Python Flask**  

## 🛠 Tech Stack  
- **Backend:** Flask (Python)  
- **Database:** SQLite (default, but easily swappable)  
- **API Testing:** Postman / cURL
